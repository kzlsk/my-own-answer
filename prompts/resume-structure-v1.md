## 반드시 지킬 것

1. 원문에 있는 문장과 단어를 **그대로 옮깁니다.** 요약, 다른 말로 바꾸기, 다듬기, 번역을 하지 않습니다.
2. 원문에 없는 내용(경험, 수치, 기술, 성과, 기간)을 절대 만들지 않습니다. 모르는 칸은 빈 문자열("")이나 빈 배열로 둡니다.
3. 숫자(기간, %, 초, 명, 건 등)는 원문 표기 그대로 옮깁니다.
4. [이름], [전화번호], [이메일], [링크], [생년월일], [가림] 같은 가린 표시와 연락처·주소·학력은 옮기지 않습니다.
5. 같은 내용이 두 번 나오면 한 번만 옮깁니다.
6. 어느 항목에도 맞지 않지만 경험에 관한 문장은 버리지 말고 uncategorized에 그대로 넣습니다.

## 항목

- summary: 한 줄 소개 (원문 그대로, 없으면 "")
- experiences: 회사 경력·인턴 (org 회사, role 역할, period 기간, details 한 일 목록)
- projects: 프로젝트 (name, period, role 맡은 역할, stack 사용 기술 한 줄, details 한 일·성과 목록, troubles 트러블슈팅 목록)
  - 트러블슈팅은 그 문제가 생긴 프로젝트 안에 넣고 problem 문제 / solution 해결 / result 결과로 나눕니다. 원문에 결과가 없으면 result는 ""
  - 프로젝트 밖에 따로 적힌 트러블슈팅은 원문에 적힌 프로젝트 이름을 보고 해당 프로젝트에 넣고, 알 수 없으면 name이 ""인 프로젝트에 모읍니다
- skills: 기술 스택 (원문 항목 그대로)
- activities: 교육·활동 (부트캠프, 학회, 동아리, 대외활동, 인턴십 프로그램 등. name, period, details)
- certificates: 자격증 (name, date)
- awards: 수상 (name, date)
- uncategorized: 분류하지 못한 경험 관련 원문 문장
