# 형식이 다른 가상 이력서 (이력서 정리 평가용)

`data/resumes/`의 가상 인물을 실제로 흔한 이력서 형식으로 다시 쓴 것입니다. 실제 인물·회사가 아닙니다.
이력서 정리(`resume-structure`) 프롬프트가 형식이 달라도 같은 섹션으로 옮기는지, 수치를 바꾸지 않는지 잴 때 씁니다.

| 파일 | 형식 | 특징 |
| --- | --- | --- |
| `f01-figma.txt` | 피그마로 만든 PDF에서 뽑은 글 | 제목 없음, 같은 줄이 두 번 붙음, 열이 섞여 순서가 흐트러짐 |
| `f02-notion.md` | 노션 페이지를 내보낸 글 | 이모지 제목, 토글(▶), 콜아웃, 표 |
| `f03-wanted.txt` | 원티드 이력서 PDF에서 뽑은 글 | 원티드 고정 섹션(간단 소개글·경력·학력·스킬·수상 및 기타·링크), 경력 아래 성과 |
