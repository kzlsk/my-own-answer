# 공고 스크린샷 판독 평가 세트

복사가 막힌 공고를 스크린샷으로 가져올 때(`/api/posting`) AI가 글자를 얼마나 정확히 옮기는지 재는 세트입니다.

| 파일 | 내용 |
| --- | --- |
| `i01-medai-frontend.png` | 공개 채용공고 화면 캡처 (㈜메드에이아이 프론트엔드, 1,258×1,029px). 사용자가 실제로 판독을 시도한 화면 |
| `i01-medai-frontend.txt` | 사람이 이미지를 보고 옮긴 정답. 원문의 오타·띄어쓰기("리자인", "및Next.js를활용한")도 그대로 둠 |

지표 (`npm run eval:ocr`):

- **글자 정확도**: 공백과 목록 기호(`-`, `#`, `*`, `·`)를 뺀 뒤 `1 - 편집 거리 / 정답 글자 수`
- **틀린 구간**: 정답과 다르게 적힌 부분 목록 (예: `의료 → 외로`)
