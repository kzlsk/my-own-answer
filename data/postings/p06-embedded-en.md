# 인피니언테크놀로지스코리아㈜ — Internship - Engineering (AI & Embedded Solutions)

인피니언테크놀로지스코리아㈜는 2001년에 설립된 회사로 자본금 25억 5,000만원, 매출액 763억 2,274만원, 사원수 260명 규모의 외국계(외국 투자기업)입니다. 서울 강남구 테헤란로 534 (대치동, 글라스타워빌딩)에 위치하고 있으며, 차량용 반도체, 전력 반도체사업을 하고 있습니다.

## 포지션 및 자격요건

Internship - Engineering (AI&Embedded Solutions) ( ○명 )

### 담당업무

**Your role**
Key responsibilities in your new role

Join our 1-year internship program and support the development and evaluation of AI and embedded solutions. You will assist with technical documentation, AI modeling activities, example code development, testing and validation, and technical demo operations

- **Technical Documentation:** Support the preparation and updating of technical documents, application notes, user guides, test reports, and presentation materials
- **AI Modeling Support:** Assist with data preparation, model training and evaluation activities, and the documentation of results using defined tools and workflows
- **Testing and Validation:** Perform functional testing and validation of embedded solutions and technical demos based on defined test procedures
- **Example Code Development:** Develop and maintain simple example code and scripts in C/C++ or Python with guidance from engineers
- **Technical Demo Support:** Assist with the setup, operation, and verification of demos using MCUs, sensors, touch, voice, vision, and AI technologies
- **Issue Investigation:** Document test results, report identified issues, and support engineers with basic troubleshooting activities.

### 스킬

- 경력 : 신입

### 우대사항

**Your profile**
Qualifications and skills to help you succeed

- **Education:** Currently enrolled in a Bachelor's or Master's degree program in Computer Science, Computer Engineering, Software Engineering, Electrical Engineering, or a related field
- **Programming:** Basic knowledge of C/C++ or Python programming
- **Development Exposure:** Experience with modeling, prototyping, or AI-assisted development tools
- **Technical Interest:** Interest in AI, MCUs, embedded systems, sensors, touch, voice, and vision technologies
- **Project Exposure:** Coursework or hands-on project experience related to software, AI, or embedded systems is a plus
- **Communication and Mindset:** Good communication skills, a proactive attitude, and a willingness to learn
- **Embedded Systems:** A basic understanding of MCUs or embedded systems is preferred
- **Application Interest:** Interest in edge AI applications involving sensors, touch, voice, or vision is preferred
