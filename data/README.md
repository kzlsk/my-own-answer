# 테스트 데이터

실제 개인정보와 회사 내부 자료는 넣지 않습니다.

| 폴더 | 내용 | 목표 개수 |
| --- | --- | --- |
| `resumes/` | 가상 인물 이력서 (프론트엔드, 백엔드, QA, 마케팅, PM) | 5 |
| `postings/` | 공개 채용공고 본문. 파일 맨 위에 출처 URL과 수집일 표기 | 6 |
| `results/` | v1·v2 실행 결과, 채점 표, 데모 모드용 샘플 | - |

테스트 세트는 이력서 5 × 공고 6 = 30건입니다. 이 중 까다로운 경우를 포함합니다: 경력이 거의 없는 이력서(`r04`), 직무가 안 맞는 조합(`p06` 임베디드 인턴 × 전체, `p05` 광고 사업 PM × `r05`), 영문 공고(`p06`), 개인정보가 많은 이력서(`r05`).

아주 긴 공고는 평가 세트에 넣지 않습니다. 대신 `tests/fixtures/long-posting.md`(공고 6개를 이어 붙인 약 11,000자 입력)로 공고 길이 제한(8,000자)을 넘는 경우를 E2E에서 확인합니다 (TC-107).
