### BUG-001 답변 초안에 마스킹 토큰 `[이름]`이 그대로 노출

- **심각도**: Minor (기능은 동작하지만 사용자가 그대로 말하면 어색한 답변)
- **관련 TC**: TC-402
- **환경**: 평가 스크립트, answer-v1, gpt-4o-mini
- **발견자 · 날짜**: 본인 · 1일차

**재현 절차**

1. `npm run eval -- --target answer --version v1 --limit 5`
2. `data/results/2026-10-29-answer-v1/scoring.csv`에서 r02-backend__p03-qa, r04-marketing__p01-frontend의 1번 문장 확인

**기대 결과**

답변에 `[이름]`, `[전화번호]` 같은 가림 표시가 나오지 않는다.

**실제 결과**

"안녕하세요, 저는 [이름]입니다." (5건 중 2건)

**근거**

`data/results/2026-10-29-answer-v1/scoring.csv` 19행, 52행

**원인**

이력서를 마스킹해서 보냈기 때문에 모델이 이름 대신 토큰을 받았고, v1 프롬프트에 인사·자기소개를 막는 지시가 없음.

**수정 내용 · 확인**

answer-v2에 "인사·이름 소개 금지, 가림 표시를 답변에 쓰지 않음" 추가.

- 확인: `data/results/2026-10-29-answer-v2` 같은 질문 5건에서 `[이름]` 노출 0건 (v1은 2건)
- 남은 일: 화면 단계에서 토큰이 남아 있으면 표시하지 않는 후처리 + E2E로 확인 후 Fixed로 닫기
